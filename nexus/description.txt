SUMMARY  (paste into the Nexus "Summary" box)
---------------------------------------------
Dungeons II shows Xbox button prompts to everyone on PC. This makes it show PlayStation ones instead, using the icons the game already shipped with. Two line config file, no game files touched.


DESCRIPTION  (paste into the Nexus description box, it is BBCode)
-----------------------------------------------------------------
I sat down with Dungeons II and a DualSense, and the game spent the whole evening telling me to press A. My controller does not have an A. Every PC player gets Xbox prompts no matter what is plugged in.

I went in expecting to repaint a pile of button icons, because that is how the old Minecraft Dungeons mods did it. Turns out none of that is needed. The PlayStation icons are already sitting in your Windows install, fully drawn and ready to go. The game just never picks them.

So this is a two line config file.

[size=4][b]Install[/b][/size]

Right-click Start, open Terminal, paste this, press Enter:

[code]$v='PS5';$r=@("$env:LOCALAPPDATA\Dungeons2");foreach($k in @(Get-ChildItem "$env:LOCALAPPDATA\Packages" -Directory -Filter '*MinecraftDungeons2*' -EA 0)){$r+="$($k.FullName)\LocalCache\Local\Dungeons2"};$h='[CommonInputPlatformSettings_Windows CommonInputPlatformSettings]';foreach($b in $r){$d="$b\Saved\Config\Windows";$f="$d\Game.ini";New-Item -ItemType Directory -Force $d|Out-Null;$l=@();if(Test-Path $f){$l=@(Get-Content $f|Where-Object{$_ -notmatch '^\s*DefaultGamepadName\s*='})};if($l -notcontains $h){if($l.Count -and $l[-1].Trim()){$l+=''};$l+=$h};$i=[array]::IndexOf($l,$h);$o=@();for($j=0;$j -lt $l.Count;$j++){$o+=$l[$j];if($j -eq $i){$o+="DefaultGamepadName=$v"}};Set-Content $f $o -Encoding UTF8;"Applied: $f"}[/code]

Restart the game. Done.

That covers Steam, Microsoft Store and Game Pass, and it does not care where you installed the game, because the config lives in your user folder instead of the game folder.

If you would rather do it by hand, drop the included [b]Game.ini[/b] into this folder:

[code]%LOCALAPPDATA%\Dungeons2\Saved\Config\Windows[/code]

Microsoft Store and Game Pass keep theirs somewhere less friendly:

[code]%LOCALAPPDATA%\Packages\Microsoft.MinecraftDungeons2_8wekyb3d8bbwe\LocalCache\Local\Dungeons2\Saved\Config\Windows[/code]

Paste either one into the Explorer address bar and it will take you there. If a Game.ini is already in that folder, add the two lines to the end of it rather than replacing the file.

[size=4][b]Uninstall[/b][/size]

Delete that Game.ini. That really is all of it. You do not need to verify your files or reinstall anything, because nothing outside your own config folder was ever touched.

[size=4][b]No prompts at all?[/b][/size]

Then your controller is not reaching the game and this mod has nothing to relabel. Check that the pad is actually awake. A DualSense that is paired over Bluetooth but asleep still shows up in Windows while being completely invisible to the game, which cost me a solid ten minutes of staring at a title screen wondering why nothing had changed. Toggling Steam Input for the game is worth a try too.

[size=4][b]Why the game gets this wrong[/b][/size]

For the curious. Dungeons II uses Unreal's CommonUI for input, and its Windows settings register every controller profile the game owns, PS4, PS5, Switch, Xbox One and Xbox Series, then set the default gamepad to [i]Generic[/i]. Here is the part that made me laugh: the Xbox One profile is the one that claims the name [i]Generic[/i]. So the default quietly resolves to Xbox for everybody on PC. Naming a different one is the entire fix.

[size=4][b]Other controllers[/b][/size]

Separate downloads for DualShock 4, Switch and Xbox Series pads. Only the PS5 one has been tested on real hardware, which was mine. The rest use the same mechanism and their names came straight out of the game's own controller assets, so I expect them to work, but expecting and knowing are different things. Let me know in the comments if you try one.

[size=4][b]Compatibility[/b][/size]

Cosmetic only, so it is safe in multiplayer. It lives in your user config rather than the game's data, so a patch should not wipe it. Built against Dungeons II 1.1.1.0 on Unreal Engine 5.6.1.
